# fsp-e1

FSP RaceBird livery showcase.

A static 3D showcase site (Google `<model-viewer>`) presenting FSP livery concepts
for the E1 RaceBird in white, FSP blue and lime (the futureofsports.io production
brand). Open the page, orbit/zoom the model, and switch liveries with the bottom bar,
the arrow keys or 1–9 / 0:

- **01 Pixel Wake**: blue stern breaking into FSP blocks with a lime edge, Future of Sports on the sides.
- **02 Telemetry**: blue waterline sweep, Future of Sports running into a 05 data line, an ASCII-texture blue nose with the F in characters (the FSP site hero), lime LED blocks.
- **03 Fingerprint**: FSP's fingerprint ridges looping round a white pixel F on the front deck, a lime scan band, 05 on the engine cover.
- **04 Current**: blue ribbons sweeping from the stern into a V on the front deck, ending in a pixel arrowhead with a lime edge.
- **05 Negative**: a split-tone blade, the front deck blue on one side and white on the other, with a counterchanged 05.

Sharp, straight-edged set (F1 / E1 team style, no curves):

- **06 Delta**: hard-edged blocking: a navy saddle, blue shards and a blue delta nose with a lime pin.
- **07 Chevron**: three FSP-blue speed chevrons charge at the nose, heaviest in front, lime-edged.
- **08 Strike**: blue, navy and lime racing stripes slash across the bow with hard pointed tips.
- **09 Blade**: twin FSP-blue blades fold over the gunwale into a sharp spear at the nose.
- **10 Shard**: a faceted blue spearhead shatters over the bow, its shards flying back along the hull.

The E1 series logos sit in their original positions on every livery. The boat renders like a
studio product shot: FSP-blue studio backdrop with a soft floor shadow, studio lighting
(`env/studio.hdr`), clear-coat reflections, baked shading in the model, and full-resolution,
anisotropically filtered textures. All page text sits behind the boat; only the controls are in front.
Link straight to one with `?v=`, e.g. `?v=fingerprint` or `?v=03`.

**Colourway:** the colourway panel (grid button) has four options for every livery:
Blue · Lime (default), Blue · Orange (each design's own orange version, `liveries/fsp-<id>-orange.png`,
where orange `#FF5B13` takes over a visible element), Orange · Blue and Dark · Lime (the
lime texture recoloured live on the GPU). Every visit starts on Blue · Lime.

**Partner logo:** the HRX logo sits on the engine hump and the rear deck flanks (both sides),
white on dark ground and ink on light ground, red tick kept; the Partner switch in the colourway
panel turns it on and off (on by default). It is a UV mask (`sponsors/hrx.png` + `hrx.json`)
composited live, made by livery-tools `sponsor.mjs` from the official logo.
The textures are generated by a separate local toolchain (`livery-tools`), not part of this repo.

## Merch

`merch.html` (switch with the Liveries / Merch toggle at the top) shows FSP team-wear
concepts in 3D: a jacket, a hoodie and a T-shirt, in six print styles (Track, Pixel Fade,
Circuit, Split, Shard, Paddock) and Blue · Lime or Blue · Orange. The prints
are painted by the local `apparel` toolchain; `merch/` holds web builds (WebP textures,
quantised geometry). Model credits: "Varsity Jacket" by Sev and "Green and white hoodie" by
Style3D CG (both CC BY 4.0, Sketchfab), T-shirt from pmndrs/examples (MIT, see
`merch/LICENSE-tshirt.txt`). Link straight to one with `merch.html?g=hoodie&s=circuit`.

## Run locally
Any static server works, e.g.:

```bash
python -m http.server 8000
# then open http://localhost:8000
```

## Deploy
Pure static — no build step. On Vercel: import this repo, framework preset
**Other**, leave the build command empty. The site is served from the repo root.
`vercel.json` lets browsers cache the model and textures for a day, so bump `ASSETS`
and the `racebird.glb?v=` in `index.html` whenever they change.

## Structure
```
index.html            # the showcase page and HUD
model-viewer.min.js   # Google model-viewer (3D web component)
racebird.glb          # the RaceBird 3D model
liveries/             # FSP livery textures (4096²)
images/               # FSP F mark (white)
fonts/                # Archivo + Azeret Mono (FSP brand fonts, from the production site)
env/                  # studio.hdr, the studio lighting
```
